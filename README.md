# Lightweight Charts Custom Indicator

This example demonstrates how to extend Lightweight Charts by adding a custom technical indicator. It calculates a simple Moving Average (SMA) from generated candlestick data and displays it as an overlay on the chart. This showcases how to integrate custom logic for financial analysis, addressing the article's theme of enhancing Lightweight Charts' capabilities.

## Language

`html`

## How to Run

1. Save the code as `index.html`.
2. Open `index.html` in any modern web browser.
